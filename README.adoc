= KratOS =

KratOS is a small hobby operating system built to learn how operating systems
work. The current system is a freestanding x86_64 kernel written in Zig, booted
with Limine and developed/tested in QEMU.

== Current state ==

The kernel boots to a text-oriented framebuffer shell with a multiline ASCII-art
welcome logo. In the graphical QEMU window, the shell accepts polled PS/2
keyboard input; COM1 serial input/output remains available for recovery and
automated testing. Built-in commands include `help`, `about`, `echo`, `mem`,
`clear`, `kratos`, and `halt`. `kratos` is a bounded kernel-mode animation and
returns to the shell when `q` is pressed. `halt` stops the guest CPU but does not
close QEMU; a guest `shutdown` command is planned in ticket 0015. Until then,
close QEMU from its host window or send Ctrl+C in the terminal that launched it.

This is an educational kernel prototype, not a POSIX system. It does not yet
provide user-mode processes, a filesystem, or arbitrary executable loading.
Keyboard support currently targets QEMU's translated US PS/2 set-1 layout;
Caps Lock, extended keys, and non-US layouts are not implemented.

== Build and run ==

Install the prerequisites and obtain the Limine v12.9.6 release files listed in
link:docs/qemu-boot.md[the QEMU boot guide]. Build and launch the graphical QEMU
system from the repository root:

[source,sh]
----
LIMINE_DIR=/path/to/limine-binary ./kratos/build-qemu.sh
----

The QEMU window is the KratOS display and keyboard input target. For headless
serial use, set `QEMU_DISPLAY=none`; serial input remains on the launching
terminal. See link:docs/qemu-boot.md[the QEMU boot guide] for detailed build,
interaction, and regression-test instructions.

== Repository layout ==

- `kratos/` contains the active Zig kernel, QEMU build/run scripts, and tests.
- `docs/` contains the roadmap, tickets, boot guide, and session log.
- `legacy/` preserves the earlier learning exercises and unused C kernel stub;
  these are archived and are not part of the current kernel build.

The original project motivation and early goals are recorded in
link:devlog.adoc[the development log].
