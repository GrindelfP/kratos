# Agent instructions

- Read `RULES.md` before starting any work; it defines the required workflow.
- KratOS is a hobby OS project. `edu/` contains learning exercises; `kratos/` contains the OS itself. Keep this distinction when adding code.
- The repository currently has no root build/test workflow. Check a directory's own build files before choosing commands; `edu/assmblr-ex/Makefile` targets macOS x86_64 assembly, not the OS kernel.
- Record each session's work in `docs/session-log.md` using its `[date] - [time] - [what was done]` format.
